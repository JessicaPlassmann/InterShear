# Code for Shearography Simulation

This folder contains the Matlab code used for shearography simulation, as presented in our submission to **Optics Express** (Manuscript ID: 572513). The code implements the algorithms described in the paper and serves as a foundation for further extension and development.

## Overview

- Implementation of the OOP shearography processing pipeline  
- Code structured for easy extension to other shearography modalities  
- Example scripts and data loading utilities included  
- Planned future extensions to incorporate in-plane simulation
